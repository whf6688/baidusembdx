## 生命周期

正常升级路径：

`F拓展 → E消耗很小 → D消耗不足 → C成本较高 → B机会 → A成本`

`成本高` 与 `空耗` 是黑名单分支。分级使用项目内所有账户的历史累计总数据；新数据会持续进入累计值，因此关键词既可能升级，也可能在累计成本恶化后降级。试算不改数据；确认执行后，成本高和空耗直接进入本项目关键词黑名单，但不调用百度。

## 当前执行规则

当加粉数大于 0：

1. `消费 ÷ 加粉数 ≤ 110`：`A成本`。
2. 否则，`消费 ÷ (加粉数 + 1) < 100`：`B机会`。
3. 否则，`消费 ÷ (加粉数 × 1.2) < 120`：`C成本较高`。
4. 其余：`成本高`。

当加粉数为 0：

1. `消费 ≥ 70`：`空耗`。
2. `10 ≤ 消费 < 70`：`D消耗不足`，不区分复制数。
3. `0 < 消费 < 10`：`E消耗很小`，不区分复制数。
4. `消费 = 0`：`F拓展`。

系统补充规则：完全没有同步到表现记录时不等同于已确认消费为 0，关键词保持当前等级；新关键词初始为 `F拓展`。

## 默认可配置参数

| 参数 | 默认值 |
| --- | ---: |
| A 加粉成本上限 | 110 |
| B 补 1 粉后成本上限 | 100 |
| C 加粉增长倍数 | 1.2 |
| C 推算成本上限 | 120 |
| 空耗消费阈值 | 70 |
| D 最低消费 | 10 |

金额按两位小数比较。Excel 中有 2 行原始浮点值为 `69.99999999999999`，Excel 缓存结果按 70 元归入空耗；后台使用金额定点化后与 Excel 结果一致。
