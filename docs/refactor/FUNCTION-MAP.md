# 重构功能映射

本表用于证明本次本地重构调整的是导航、页面层级、交互和数据聚合入口，原业务规则和百度写入安全链路不被绕过。普通浏览只读取搜索项目 PostgreSQL，不因展开行、筛选或翻页调用百度。

| 业务能力 | 重构后入口 | 保留或新增的行为 | 兼容边界 |
| --- | --- | --- | --- |
| 管家授权与同步 | 项目与账户 → 账户管理 | “账户管家 + 每个具体管家”页签；表头统一为类型、账户、账户余额、返点、授权、操作、充值账户 | 使用搜索项目独立 OAuth 与授权中心；余额直接读取管家初始绑定的充值账户 |
| 删除管家 | 账户管理 → 删除管家 | 本地归档管家并停止其下账户同步和自动任务 | 保留历史数据，不修改百度端账户；已归档管家不进入日常页签 |
| 账户经营与批量操作 | 项目与账户 → 账户列表 | 日期与多维筛选、跨行多选、批量时段、批量暂停/启用、生命周期、后台分页和排序 | 批量写入仍经过预检、目标账户、计划缓存、限频、审计、幂等和回读 |
| 账户指标概览 | 账户列表顶部 | 展现、点击、消费、UV、复制、加粉、成本和现金口径集中展示 | 概览已从数据报表移除；指标全部来自后台，不在前端重算 |
| 计划查看 | 账户列表 → 点击账户名称 | 展开当前账户的本地计划缓存和计划状态 | 普通展开不调用百度；计划 ID 仅在明确重建后失效 |
| 自动搭建 | 项目与账户 → 自动上线 → 自动搭建 | 自动搭建位于最左；选择账户、模板与执行时间 | 四种选户、多日期 × 多时间、无限日期队列、5,000 词拆分和断点恢复保留 |
| 优选模式 | 自动上线 → 自动搭建 | 沿用 A–F 关键词分级和既有分配 | A 最大化、B/C 测试、D/E/F 补充分配的默认语义不变 |
| 全量模式 | 自动上线 → 自动搭建 | 全部非黑名单关键词按原始计划投放到每个账户，每个关键词每账户一次 | 仍按每单元最多 5,000 词拆分；预检时冻结物料摘要和指纹，创建时校验 |
| 物料中心 | 自动上线 → 物料中心 | 导入、分级规则、否词、黑名单、年份筛选、后台分页 | 不再提供“总计”时间项；默认当前年，若无数据自动切换到最近有数据年份 |
| 创意中心 | 自动上线 → 创意中心 | 三段创意、随机组合、审核治理与组合黑名单 | 原字节限制、去重、拒审累计和自动补齐规则不变 |
| 自动上线执行记录 | 自动上线 → 执行记录 | 一行一个账户，显示批次、优选/全量模式、进度、结果和安全续跑 | 展示物料预检、账户设置、计划、单元、oCPC、关键词、人群、创意、回读验证九个节点 |
| 自动策略 | 系统设置 → 自动策略 → 策略管理 | 预算重置、预算追加、账户淘汰、关键词分级、闭环检测统一管理 | 每个策略独立拥有规则、执行记录、结果、试运行和版本历史，不再设独立“执行记录”导航 |
| 策略编辑 | 自动策略 → 规则设置 | 草稿、参数校验、试运行、发布、版本历史和恢复 | 未主动发布时使用初始化的 v1，候选账户与旧规则一致 |
| 60 分钟闭环 | 自动策略 → 闭环检测 / 项目刷新 | 闭环周期在“项目刷新”中可配 15–1440 分钟；每分钟只判断是否到期 | 数据不完整时保护闸仍禁止自动写入；余额查询纳入闭环 |
| 预算重置 | 自动策略 → 预算重置 | 默认每日 00:00，日预算固定为已发布规则中填写的金额 | 仅启用、未淘汰、测试期、预算快照在 60 分钟内且当前预算不等于填写金额的账户进入候选 |
| 预算追加 | 自动策略 → 预算追加 | 默认成本 < 100、利用率 > 80%、追加 50 元 | 仍要求加粉 > 0，并按边际效果决定是否继续追加 |
| 账户淘汰 | 自动策略 → 账户淘汰 | 淘汰记录、黑名单和次日最终归档 | 消费 > 100 且无加粉，或加粉成本 > 120；已淘汰账户不重复调用 |
| 数据报表 | 项目与账户 → 数据报表 | 日期、页面类型、运营、搜索、排序与导出 | 只保留明细报表，不再重复显示账户概览 |
| 项目管理与项目切换 | 系统首页 `/`；点击左上角“搜索投放平台”随时返回 | 项目表、创建、编辑、进入项目和新标签打开；每个项目进入独立工作台 | 项目编码创建后不可修改；项目路径为 `/{项目编码}?page={页面}`；数据仍按项目隔离 |
| 成员管理 | 系统设置 → 成员管理 | 管理管理员、王康、王聪的自动搭建状态、运营账户范围与可用账户数 | 三个成员功能权限一致；登录密码由服务器认证层管理，不在页面展示或修改 |
| 项目刷新 | 系统设置 → 自动策略 → 项目刷新 | 全项目闭环刷新周期、页面时区和自动化数据保护闸 | 覆盖账户、百度报表、好多粉、预算、创意和归因，不属于数据报表页 |
| 参考模板与运行状态 | 系统设置 → 自动策略 → 参考模板 / 运行状态 | 配置集中在自动策略 | 密钥永不展示；写入安全链路不变 |
| 页面时区 | 系统设置 → 自动策略 → 项目刷新 | 北京时间或 UTC，保存后作用于账户、策略和任务时间显示 | 入库时间仍为 UTC，不修改后台事实数据 |
| 全局刷新 | 页面右上角 | 在任意页面刷新当前项目的账户、管家、任务、提醒和运行状态；浏览器刷新后保持当前页面和自动上线子页签 | 不再固定到数据报表；普通刷新不绕过后台同步调度 |
| 全局提醒 | 页面右上角 | 任务状态、后续退款、余额不足提醒和全部已读 | 余额提醒继续使用主体 + 钱柜、近 7 天消耗和不足 2 天支撑规则 |

## 路由与导航收敛结果

- 根路径 `/` 是系统首页；仅展示项目管理；不再把项目选择嵌入任一项目工作台
- 点击项目名称、进入项目或新标签打开都使用真实链接 `/{项目编码}?page=account-list`；新标签不会继承或覆盖其他标签的项目上下文
- 已进入项目后，左侧分为两个同级导航组：“项目与账户”和“系统设置”。
- “项目与账户”顺序为：账户管理、账户列表、自动上线、数据报表。
- “系统设置”包含：成员管理、自动策略；项目刷新、参考模板和运行状态继续位于自动策略内。
- 左上角系统名称是返回项目管理的入口；工作台顶部不再显示项目选择器或项目标题
- 删除独立“执行记录”导航；自动上线记录进入自动上线页签，策略记录进入各策略页签。
- 物料中心、创意中心和自动搭建不再分散在左侧，统一为自动上线内的四个平级工作区。
- 旧查询参数 `page=execution-records` 仍兼容跳转到自动上线执行记录，避免旧链接失效。

## UI 与操作规范

- 采用与电商后台一致的浅灰工作区、紧凑标题、单行工具栏、平直页签、蓝色主操作和高密度表格。
- 正文统一黑色/深灰；蓝色仅用于可操作、选中和进度，绿/黄/红仅用于有业务含义的状态。
- 表格正文不加粗，账户名称等主字段才使用适度强调；表头、行高、分页和空状态统一。
- 对话框统一标题、简短说明、内容区和右下角取消/确认；危险动作继续二次确认。
- 1366、1440、1920 三种桌面宽度均保留完整操作入口，宽表在内容区横向滚动。

## 数据边界

- 新聚合接口只读 `search_marketing`；策略版本、试运行和调度事实只写 `search_marketing`。
- 百度 Token 仍只从本项目 `platform_core` 读取。
- 没有读取电商数据库、应用配置、Token 或业务代码；仅观察其页面结构与样式规则。
- 没有新增 SQLite，也没有发布或修改线上环境。
