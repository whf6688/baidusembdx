## 关键业务边界

- 预算重置：默认 00:00、默认 50 元且可发布为其他固定金额；仅启用、未淘汰、测试期、预算快照在 60 分钟内且当前预算不等于固定金额。
- 预算追加：加粉数严格大于 0、成本严格小于 100、利用率严格大于 0.8，单次追加 50 元。
- 账户淘汰：累计消费严格大于 100 且无加粉，或加粉成本严格大于 120。
- 已淘汰黑名单、次日最终归档、四种选户、日期时间笛卡尔积、无限日期、计划缓存、动态限频、幂等和回读的既有测试仍通过。
- 全量模式不筛选 A–F，但排除黑名单；按原计划归组，每个关键词每账户一次，单元最多 5,000 词。
- 自动上线预检冻结物料快照并生成指纹，提交时物料变化会阻止创建，避免预览与实际投放不一致。

## 本地运行抽查

- scheduler 的分钟检查任务正常运行；验收期间自动上线、策略和数据周期调度均返回 0 个到期任务，没有触发真实百度写任务。
- 项目管理的新建/编辑弹窗只做了打开与取消检查，没有写入测试项目。
- 成员管理显示管理员、王康、王聪三个系统成员；功能权限一致，管理员固定全量范围，并显示各自可用账户数。
- 账户管理余额读取充值账户现有余额；删除管家按钮保留归档确认流程。
- 物料中心年份选择不含“总计”；项目刷新中的时区已接入页面时间格式化。
- 系统首页只展示项目管理；进入项目后，“系统设置”与“项目与账户”作为同级导航组，包含成员管理和自动策略。
- 页面右上角提供全局刷新入口，不再将刷新表现为数据报表专属能力。
- 浏览器刷新会恢复当前导航页面；自动上线的四个子页签同样保持，不再跳回数据报表。
- 根路径 `/` 只显示项目管理；项目工作台使用 `/{项目编码}?page={页面}`；例如 `/jfsem?page=account-list`；多个浏览器标签可分别打开不同项目
- 普通页面浏览、账户展开、筛选和分页只访问本地网页/API，没有产生外部网络请求。
