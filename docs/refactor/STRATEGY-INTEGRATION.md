# 自动策略集成（2026-09-14）

本地策略入口已收敛到投放运营下的“自动策略”。参照本机电商自动策略的实际页面，使用分组动作页签、内容页签、右侧编辑入口和页头发布入口。

- 周期调整：预算重置、预算追加。
- 账户与物料：账户淘汰、关键词分级。
- 运行检测：闭环检测。
- 每项动作有独立执行记录。预算重置与追加按各自任务类型精确过滤；淘汰按淘汰任务过滤；关键词展示部署/轮换任务；闭环展示账户报表、关键词报表、好多粉、预算快照和创意审核任务。
- 预算变更明细、淘汰明细保留原接口的日期和分页。
- 规则设置、执行记录、试运行结果、版本历史分开展示；修改前需点击编辑规则，参数和执行业务规则保持原样。
- 不再保留左侧独立执行记录导航：自动上线记录位于自动上线页签，预算和淘汰等记录位于各自动策略的执行记录页签。

验证：类型检查、8 项组件测试和 12 项浏览器测试通过，其中独立样本验证预算重置、预算追加、淘汰的任务记录互不混入。前端生产镜像构建成功并在本地 8280 端口更新；未发布线上。
