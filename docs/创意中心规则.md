# 创意中心规则

## 创意库

- 创意标题、创意描述1、创意描述2分别保存，每个项目内同一分段内容唯一。
- 创意标题按百度规则限制为9–50字节，创意描述1为9–80字节，创意描述2为0–80字节。
- 创意描述2的空值不保存为普通分段，随机组合时作为一个合法选项参与。
- 被停用的分段不参与随机组合。

## 投放组合

- 投放预检要求至少存在50个可用组合。
- 每个目标账户使用项目、选择种子和百度账户ID生成稳定随机结果，并固定50个互不重复的组合。
- 创建投放任务时把组合及其投放槽位写入PostgreSQL，不能在执行时临时重新随机。
- 已进入组合黑名单的内容不再参与任何账户的随机选择，也不允许再次提交。

## 审核治理

- 已登记百度创意ID的测试期账户投放记录，在每日 1:00–23:00 整点查询一次 `CreativeService/getCreative`。
- `offlineReasons.mainReason = "3"` 对一跳账户和二跳账户都统一代表审核不通过。
- 一跳账户：删除审核不通过的百度创意，再随机补齐到50条；不累计组合拒绝次数，原组合允许以后再次提交。
- 二跳账户：每个投放实例只记录一次拒绝；同一组合累计5次审核不通过后自动进入组合黑名单。前4次拒绝仍允许该组合再次提交。拒审创意删除后按过滤黑名单后的组合池自动补齐。
- 二跳账户每次拒审还会给该组合中的创意标题、创意描述1和非空创意描述2原料分别累计1次拒绝；任一原料累计50次后自动进入原料黑名单。
- 原料黑名单不可恢复使用；包含黑名单原料的全部组合都会从后续随机选择和补齐中排除。
- 组合黑名单只能由二跳账户的真实审核结果产生，没有人工加入或人工移出接口。
- 删除与补齐均经过公共限频、权限、审计和幂等层；只有独立的创意自动重建开关启用时才允许执行，通用百度写入开关仍保持关闭。

## 百度接口

- 查询：`json/sms/service/CreativeService/getCreative`
- 新增：`json/sms/service/CreativeService/addCreative`
- 删除：`json/sms/service/CreativeService/deleteCreative`

字段和行为依据共享知识层 `DOC-0567`、`DOC-0568`、`DOC-0569`、`DOC-0571`。
