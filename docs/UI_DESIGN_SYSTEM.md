# 搜索投放管理平台 UI 规范

本规范用于数据后台的所有现有与新增页面。视觉基调保持克制、清晰和高信息密度，优先保证宽表、筛选、批量操作和任务状态的可读性。

## 1. 信息层级

- 页面标题：20px、600–650 字重；标题后的说明使用 12px 次级文字并与标题同行。
- 分区标题：14px、600 字重；说明使用 11px 次级文字并与标题同行。
- 表格表头：11px、600 字重。
- 表格正文：12px、400 字重；业务内容不使用加粗制造层级。
- 次级信息：10–11px，仅用于时间、水位、ID 补充说明和辅助提示。

## 2. 间距与尺寸

- 基础控件高度：34px。
- 表头高度：40px。
- 表格正文行高：46px。
- 面板标题栏高度：54px。
- 面板圆角：10px。
- 页面区块间距：14–16px。
- 页面内容应尽量利用可用宽度，宽表允许横向滚动，不通过压缩正文到 10px 以下解决列数问题。

## 3. 颜色

- 正文：`#202622`。
- 次级文字：`#66716b`。
- 弱提示：`#8a948f`。
- 边框：`#dce3df`。
- 浅表头背景：`#f7f9f8`。
- 主操作色：`#0b8a5c`。
- 选中背景：`#e9f6f0`。
- 错误色：`#b42318`。

正文数据以黑色为主。绿色只用于主操作、选中态、成功状态和轻量强调，不用于普通表格内容。

## 4. 表格

- 文本列左对齐；数值、金额、比率列右对齐；状态列可居中。
- 金额和数字启用等宽数字显示。
- 正文统一 12px、400 字重，不单独加粗账户名或关键词。
- 表头统一浅灰背景和底边框，不使用大色块。
- 悬停行仅使用很浅的背景提示。
- 超长文本单行截断，并通过 `title` 提供完整内容。
- 空值统一显示“—”；不显示伪造的 0 或无穷值。
- 宽表保留横向滚动，并保持表头可见。

## 5. 筛选与日期

- 筛选区域作为工具条使用，不做成高占用的大卡片。
- 常用日期只提供：今日、昨日、近7日、近30日和自定义范围；搜索项目不提供“总计”。
- 自定义日期使用双月范围选择，第一次选择开始日期，第二次选择结束日期，完成后自动收起并刷新报表。
- 好多粉抓取只使用自定义范围，不提供快捷日期，且继续遵守最大 31 天和不能选择未来日期的业务校验。
- 数据水位固定放在筛选工具条右侧；窄屏时换到下一行。

## 6. 弹窗

- 弹窗固定分为标题、可滚动内容、操作区三部分。
- 标题 16px、600 字重；说明 12px 常规字重。
- 内容区超高时独立滚动，操作按钮始终保留在底部。
- 主按钮放右侧，取消按钮在主按钮左侧。
- 普通弹窗宽度 520–640px；批量编辑 760px；规则和宽表预览可放宽到 980–1120px。
- 危险操作必须明确影响范围，不能只显示“确定”。

## 7. 响应式

- 桌面端是第一优先级。
- 980px 以下筛选工具条允许换行。
- 680px 以下日期选择器显示单月，表格保留横向滚动。
- 不通过缩小正文解决窄屏问题。

## 8. 实现约束

- 全局设计令牌和基础组件规则集中在 `frontend/src/styles.css` 的 `Unified data-console UI system` 区块。
- 日期范围组件位于 `frontend/src/components/DateRangePicker.tsx`。
- 新页面应复用 `.page-heading`、`.panel`、`.panel-head`、`.table-panel` 和统一日期组件。
- 核心指标继续只显示后台返回值，前端不得为视觉展示自行重算。
